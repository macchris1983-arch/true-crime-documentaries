# Episode 01: Villisca 1912, The Inventory

True crime documentary episode on the unsolved 1912 Villisca, Iowa murders.
Argument: the case did not go unsolved only because evidence was lost; for nineteen years the file kept growing.

No one has ever been convicted of these murders. Rev. Lyn George Kelly was tried and acquitted. Frank and Albert Jones were never charged.
