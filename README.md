# True Crime Documentaries

Production files for a documentary channel covering unsolved murders and massacres, built from court records, government records and public domain sources.

| Episode | Case | Status |
| --- | --- | --- |
| [01](episodes/01-villisca-1912/) | Villisca, Iowa, 1912 | First cut done; second cut in progress |

Each episode folder holds its script, voice files, edit plan, archival scans and render code.

People named in these films are presumed innocent unless convicted. A document shows a claim was made, not that it was true.
